# Student Attendance Monitoring & Performance Analysis

## Overview

The **Student Attendance Monitoring & Performance Analysis** project uses R to analyze student attendance records and identify patterns in class participation and absenteeism.

The project focuses on identifying students who may be at risk of falling below attendance requirements and examining factors that may contribute to absenteeism. The analysis provides useful insights that can support early intervention and improve student attendance monitoring.

## Project Objectives

The main objectives of this project are to:

- Analyze student attendance records using R.
- Calculate and summarize student attendance rates.
- Identify attendance patterns and trends.
- Identify students at risk of falling below attendance requirements.
- Examine factors that may contribute to student absenteeism.
- Visualize attendance trends using appropriate charts and graphs.
- Generate insights that can support attendance monitoring and student intervention.

## Research Questions

The analysis aims to answer the following questions:

- What is the overall student attendance rate?
- How does attendance vary over time?
- Which students are at risk of falling below attendance requirements?
- Which courses or programs experience higher absenteeism?
- Are there specific days or periods associated with higher absenteeism?
- What factors appear to contribute to poor attendance?

## Dataset

The dataset contains student attendance information used to evaluate attendance patterns and performance.

Key variables may include:

- Student ID
- Program or course
- Class date
- Required attendance hours
- Hours attended
- Hours absent
- Attendance rate
- Attendance status

## Methodology

The project follows a structured data analysis process:

1. Import the attendance dataset into R.
2. Inspect and clean the data.
3. Handle missing or inconsistent records.
4. Calculate attendance rates and summary statistics.
5. Analyze attendance patterns across students, courses, and time periods.
6. Identify students who may be at risk.
7. Create visualizations to communicate key findings.
8. Interpret the results and provide recommendations.
